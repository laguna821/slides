자동 목차·현재 위치·문단 링크, 본문/Markdown 복사, Markdown 저장, 코드 복사, 이미지 확대, 공개 자료 연결 지도를 공통 읽기 화면으로 구현했다. 지도에서는 실제 인용·역링크와 공통 주제를 구별한다. 관계 대상은 listed 자료만 사용한다. 원문을 검색·목차·내보내기의 단일 소스로 사용하며 원본 HTML/PDF/포스터는 수정하지 않았다.

## 검증 근거

- Astro/TypeScript: 오류·경고 0. 회귀 테스트 40개 통과. 본문 누락, 이미지 해시, 위험 HTML/이벤트, 앵커 충돌, 위키 미해결, 비공개 관계, 읽기 검토 영수증 누락을 차단한다.
- Edge 정적 미리보기: 35경로 × 375/768/1440px × light/dark = 210개 실제 DOM 검사. 요청 폭과 실제 CSS 폭을 대조했다. 가로 넘침·깨진 로드 이미지 0. Motion embed 8개는 감상용 dark 고정임을 별도로 기록했다.
- 네 읽기 화면: 복사 성공 표시, 실제 다운로드 파일의 Markdown 바이트 일치, 목차/문단 주소 이동, 이미지 확대, 지도/대응 목록 확인. 이미지 없는 AI 파일럿의 확대 항목은 해당 없음.
- 본문 검색 `HEPI`: 1개 결과 및 원문 문단 링크. 빈 결과, 새로고침, 뒤로 가기로 검색어·상태 복원 확인.
- 320px에서 실제 본문 글자를 34px, 제목을 60px로 확대한 로컬 전용 스트레스 fixture에서 가로 넘침 없음. 이 검사는 글자 2배 확대이며 브라우저 UI의 네이티브 200% 줌 시험과는 구별한다.
- 클립보드 거부 fixture: 본문 전체가 선택된 대체 복사 창 확인. 도구 패널 Shift+Tab/Tab 순환과 Escape 후 열기 버튼 초점 복원 확인. 자동화 세션 클립보드와 OS 클립보드가 달라, OS 버퍼의 바이트 일치까지 확인했다고 주장하지 않는다.
- 인쇄 스타일: 빌드된 HTML/CSS를 WeasyPrint 70으로 렌더링해 도구·목차·본문 바로가기 제외 및 모든 PDF 텍스트의 페이지 경계 이내 배치를 확인했다. 원본 그림이 포함된 페이지를 육안 확인했다. 실제 종이 출력/프린터 드라이버 검수는 포함하지 않는다.

검증 상세는 `validation/release-review.json`에 코드·자산 digest와 함께 기록한다. 원본 포스터의 독립 HTML/자산이 같은 해시일 때만 기존 순환 기하 검토를 유지한다. 이번 변경 후 사이트 화면은 다시 확인했다. 테스트 전용 fixture는 `.local`에만 유지하며 공개 빌드에 포함하지 않는다.

## 검수 중 수정한 문제

HTML의 시각적 제목 줄바꿈이 별도 문단이 되는 문제, 중복 제목, div 표의 문단화, 읽기 Markdown에서 생기는 잘못된 강조 구분자를 정리했다. 원본 텍스트 대조를 다시 통과했다. SVG 도해는 다크 화면에서도 읽을 수 있도록 흰 바탕을 제공하고 확대 창 폭을 수정했다. 이미지 원본 치수를 명시해 로딩에 따른 이동을 줄였다.

첫 인쇄 시험은 production CSS가 없는 dev 서버를 참조해 실패했다. dist 서버로 바꾼 뒤 실제 인쇄 스타일을 확인했고, 육안 검사에서 발견한 고정 '본문으로 이동' 링크도 숨겼다. 이벤트 속성 거부 코드를 추가한 뒤 발생한 TypeScript 노드 타입 오류를 타입 검사로 잡아 수정했다. 이 과정과 브라우저 입력의 간헐적 자동화 실패는 AS019에 기록했다.
