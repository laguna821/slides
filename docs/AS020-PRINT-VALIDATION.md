총 38쪽·51개 이미지. 실제 PDF를 PyMuPDF 1.27.2.3으로 다시 열어 A4 크기·폰트 포함·페이지 수·본문 조각의 실제 좌표별 텍스트·이미지 영역의 잉크를 검사했다. DOM에서는 원문 문자와 순서·그림 수·페이지 경계·표 앞뒤의 시각적 읽기 순서를 검사했다. 최종 전 페이지 렌더를 검토했다. 원본 스크린샷의 미세한 글씨는 원본대로 보존되므로 확대 열람이 필요할 수 있다.

Playwright 1.62.1 / Chromium 151.0.7922.34는 로컬 PDF 산출에만 사용했다. 사용자 브라우저 검사는 Edge CUA로 수행했다. 35개 경로 × 375·768·1440 CSS px × 밝음·어두움, 총 210개 화면에서 가로 넘침과 깨진 이미지가 없었다. 모션 내장은 기존 저작 상태에 따라 어둡게 유지된다. 네 reader의 목차·앵커·복사 응답·Markdown 다운로드·이미지 확대·관계도를 점검했고, 네 PDF를 실제 다운로드해 공개 파일과 SHA-256이 일치함을 확인했다.

Harness PDF 버튼은 실제 새 탭을 열었다. 이어 Edge의 PDF 확장 UI가 자동조작을 막아 뷰어 내부 조작과 나머지 세 PDF의 새 탭 열기는 확인하지 못했다. 다운로드 바이트 검증과 HTTP 검증으로 보완하고 검토 영수증에 제한을 명시했다. 네이티브 인쇄 대화상자·실물 프린터·PDF/UA 인증은 검증 범위에 포함하지 않는다.

긴 제목, 긴 URL, 중첩 목록, 65행 표, 100행 코드와 세로 이미지·캡션의 별도 비공개 스트레스 원고는 6쪽으로 생성돼 같은 검사에 통과했다. 원문/메타데이터 변경 시 PDF 재생성 강제, 누락·오래된 검토 거부, 브라우저 제한 예외의 필수 증거를 회귀 검사에 포함했다.
