# 한·영 포트폴리오 운영 계약 · 5.1.0

모든 새 자료와 수정은 [게시 확인 규약](UPLOAD-CONTRACT.md)에 따라 자동 감지·검사·확인 요청까지 준비하고, 사용자 확인을 받은 동일 버전만 운영에 반영한다.

한국어 `/`와 영어 `/en/`은 같은 레이아웃과 프로젝트 식별자를 사용한다. 웹 UI와 읽기 본문은 Achmage SameTone 1.000 완성판 가변 WOFF2를 자체 호스팅한다. 굵기 범위는 100–900이다. 코드와 미지원 기호에는 기존 대체 글꼴을 사용한다. 고정된 원본 발표·포스터·PDF·영상·로고는 유지한다. HanMark PDF는 승인된 기존 Pretendard 조판 프로필을 유지한다.

## 번역과 산출물

`content/i18n/en.json`의 검토된 문장 사전으로 빌드 시 영어 정적 HTML을 생성한다. 런타임 번역이나 자동 요약을 하지 않는다. 번역이 빠진 한국어 문장은 빌드를 차단한다. 작성자 한글 이름과 보존 원본 이미지는 예외다. 코드 블록은 원문대로 보존한다. 읽기 네 편의 HTML·텍스트·Markdown·검색·PDF는 같은 번역 본문을 사용하고 원문 앵커를 보존한다.

영어 편집 가능한 도해 12개는 별도 파생 SVG로 만들고 원본·파생본 해시를 `figure-manifest.json`에 기록한다. 변경 시 번역 문장과 PDF를 함께 갱신한다. 원본 스크린숏에는 영어 주변 설명을 제공한다.

`npm run build`로 한국어와 영어를 함께 생성한다. 번역 본문/도해/조판 입력이 바뀌면 `npm run print:english`로 PDF를 재생성한 뒤 다시 빌드한다. 입력 해시, PDF 파일 해시, 전체 텍스트, 이미지, 폰트 내장, A4와 경계 검사를 통과해야 한다. 생성된 모든 PDF 쪽을 시각 검토한다.

## 탐색과 공개

대응 페이지의 언어를 전환하며 해시와 검색어를 유지한다. 언어별 주제 필터는 초기화한다. 언어별 canonical/hreflang·사이트맵·검색 색인을 생성한다. 원본 발표/포스터 링크는 기존 주소를 유지한다. SameTone 프로젝트는 대표작·전체 자료·상세 페이지와 하단 크레디트에서 공식 폰트 배포 사이트로 연결한다.

모든 공개 경로를 375/768/1440px 밝음·어두움에서 검토한다. 양언어 읽기는 320/1920px, 키보드, 고정 탐색, 복사, 다운로드, 확대, 테마 위치 유지도 검사한다. 기존 release:verify 게이트를 유지하며 영어 PDF 검토도 포함한다.
