# Achmage design contract

R1 독자: 교수자·교육 관계자·제작 작업에 관심 있는 방문자, 그리고 자료를 다시 쓰는 저자.
R2 장르: 선별 포트폴리오 + 검색 아카이브. 고정 캔버스 덱이 아니다.
R3 흐름: 정체성 → 선별 작품 → 모션의 범위 → 최근 실험 → 제작자.
브랜드: 사용자가 기존 사각 ACH안을 거절하고 세 번째 A·궤적·별빛 시안을 선택했다. 이후 소문자 chmage.의 한붓 필기체와 네이비 중심 그라데이션을 요청했다. 최신 교정에 따라 A의 상승 획을 뒤로 꺾지 않고 유지한다. A와 c는 광학적 흐름으로 이어지며 하나의 연속 경로라고 주장하지 않는다. 최종 곡선 시안에 대한 별도 사용자 승인은 아직 기록되지 않았다. 심벌과 필기체 통합형, 단색·반전 세트를 /brand/에서 제공한다.
토큰: Navy #002E6E, Blue #0066B3, Teal #00B5AD. 작은 밝은 바탕 글자는 #007F7B로 대비 확보. Pretendard 한 계열.
넓은 12분할 개념 그리드, 콘텐츠 높이 중심. 검색 화면과 작은 정보 구간은 100svh 및 이미지 밀도 하한 면제: 자료 탐색 기능이 우선이다.
코퍼스 조회: component-consulting-v3 tailark:mist/hero-section/six 실제 코드 확인. 제목·소개·행동·이미지의 슬롯 구조만 참고하고 자체 Astro/CSS로 재구성. 원본의 중앙 좁은 폭, 광고 로고, 그라데이션 로고는 사용하지 않는다.
HAND-ROLL: 검색 카드와 영상 구간 도구는 이 프로젝트 데이터에 맞게 작성. card+section 조회 결과0, 가장 가까운 hero 이미지/CTA anatomy를 확인했다. 코퍼스에서 가져온 코드로 주장하지 않는다.
이미지 씬: frame(히어로), paper(발표·소개), meal(대표작), city/book/racing(모션 스트립). 텍스트는 HTML. 본문 글자가 사진 위에 겹치지 않는 구성이 기본.
모션: 사용자 선택 hover, 단일 영상 재생, preload none, muted, reduced-motion. 자동 캐러셀 없음.
Render QA 계약: widths375/768/1440 × light/dark 전수 +1920/2560 넓은 화면. 검색/작품/읽기/삽입 화면과 모든 홈페이지 구간. SCRIM=없음(텍스트/사진 분리), 폭 토큰=gutter,prose,reader. 도큐먼트 구간의 밝기 교대·전체화면 높이 요건 면제 이유 위에 명시. 구조/대비/스크린샷/이미지 관측성을 실제 화면에서 확인한다.
