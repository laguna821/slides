102장 후속 독립 검토는 전체 HTML·PDF와 판면 6장을 읽고 **발표를 막는 배치 결함 없음**으로 판정했다. 편집 데이터의 노드 429개와 출력물 간 누락도 없었다. 이 독립 검토가 최초 원고 332단위 대조나 브라우저 검사를 재현한 것은 아니다.

정적 PDF는 HTML과 같은 **102페이지**, 해당 페이지의 제목·문단·목록 단위 누락 0, 실제 원본 이미지 배치 11개를 대조했다. PDF 텍스트 추출 순서는 각주 위치와 다를 수 있어 문서 전체 문자열 순서 대신 각 원문 단위를 해당 페이지에서 검증했다. A2는 별도로 1페이지와 원문 23개 필드를 검증했다.

브라우저 진입 모션이 끝나기 전의 빈 프레임은 증거에서 제외했다. CUA에서 지원되지 않는 createTreeWalker/parseFloat만 호환 순회·숫자 변환으로 바꾸고 실제 Range 측정과 승인 checker를 유지했다. 실제 브라우저 전체 조건의 최종 결과는 검수 영수증에 기록한다. 물리적 iPhone·프린터 실기 검증은 포함하지 않는다. 전체화면은 Edge가 브라우저 제한 메시지로 거부해 성공으로 기록하지 않았다.
