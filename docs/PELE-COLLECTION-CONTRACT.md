# Pele 전체 검토실 공개 · 6.4.0

2026-10-22 사용자는 전체 사례를 포트폴리오 안에서 로그인 없이 볼 수 있게 요구했다. 소유자 전용 GPT Sites 링크만 제공한 이전 연결판은 요구 미충족이다. `/pele/`가 공개 원본 사례집의 진입점이다.

- `content/pele-collection.json`에 명시한 301개 파일만 등록한다. 39개 도표군, 104개의 중복 없는 실제 입력/SVG 사례, 46개 HTML, 한글 예제 3개를 보존한다. 폭·테마·상태를 유형 수에 더하지 않는다.
- 원본 한글 사례집의 내용·데이터·엔진 핀·라이선스를 유지한다. 포트폴리오 소개는 한영으로 제공한다. 보존된 기존 산출물처럼 사례집의 한글 입력·화면을 번역 완료로 주장하지 않는다.
- HTML은 `web-dist/pele/`에서 제공한다. 나머지 255개 파일은 기존 R2 업로더에 해시 기반 이름으로 등록하고 공개 HTTP·바이트·MIME를 확인한다. Vercel의 정확한 파일별 rewrite로 `/pele/` 아래 주소를 유지한다. 소유자 로그인·ChatGPT·쿠키·개인 OS에 의존하지 않는다.
- 원본 SHA256과 경로 변경 후 SHA256을 둘 다 기록한다. 기존 자산을 덮어쓰거나 다른 R2 파일을 삭제하지 않는다. 대용량 원본과 실행 엔진도 배포본에 포함된 것으로 검증하며 이름만 링크하지 않는다.
- 24MiB 전체 한도, 1MiB HTML 한도 및 기존 PDF/ZIP 제외 규칙을 유지한다. HWPX는 사용자가 요청한 실제 한글 예제이며 세 파일을 명시적으로 공개한다.
- `sync-pele-collection.ts`는 준비 단계에서만 업로드한다. CI는 파일 해시와 정확한 rewrite, 고유 사례 수를 검사한다. 검증용 프리뷰도 같은 공개 자산을 프록시한다.
- 공개 전 104개 사례의 원본·데이터·SVG, 39개 도표군 탐색, 기능 복구, SVG/PNG, HWPX 다운로드를 검사한다. 실제 물리 기기 및 문서 앱 저장·재열기 검증은 여전히 별도다.

공개 파일은 `.gitattributes`의 `public/pele/** -text`로 Git 체크아웃의 줄바꿈 변환을 막는다. 등록된 실제 바이트와 해시는 Windows와 Linux에서 동일해야 한다.

검토 과정에서 세 보조 페이지의 긴 해시와 grid 최소폭 때문에 생긴 작은 화면 넘침을 수정했다. 수정 후 포트폴리오 184경로의 1,104조건 및 사례집 104사례의 624조건을 실제 Edge에서 재검사했다. 물리 기기 검증과는 구분한다.
