# Pele demo contract · 6.2.0

The catalog kind `demo` identifies a technical demonstration, not an actual conference presentation. It uses the existing /talks/ detail convention and does not imply an event or affiliation. The selected demo has a separate bilingual source walkthrough; it does not claim a full slide transcript or add a reader/PDF requirement.

Pele 1.6.0 renders companion relationship maps from Mermaid flowchart source. Scientific charts are authored SVG using previously computed public-data estimates. The original conference HTML is preserved by exact hashes; website-only explanations and code must not be inserted in it. Web asset extraction follows STORAGE-CONTRACT 6.1.0 with original engine pins and content preserved.

The two explicitly hashed Pele originals have null speaker-notes envelopes and no authored notes. They remain in that original state at the user's request. The preservation check fails if bytes, demo identity or null envelope change. This does not waive note protection for other decks or claim working password protection on this demo.

Code is HTML-escaped, non-executing, keyboard reachable and copyable. Shared helpers and exact cached analysis inputs are linked. The source excerpt is a production branch requiring those helpers, not a standalone program or Pele-only reproduction of a statistical plot. Public assets are an explicit allowlist, excluding raw session records and OS instructions. No new renderer or active skill installation is included.

Existing catalog, both languages, six viewport/theme states per generated page, reader navigation and release gates apply. Final publication requires current user confirmation under UPLOAD-CONTRACT.

Source-code styling is shared at build time: 21,240 repeated token declarations in 38 bilingual pages become eight CSS rules, retaining both Shiki theme colors and exact code text. No browser highlighter is added. Measured web-dist is 24,204,177 bytes (23.08 MiB), down 634,043 bytes from the same 18-example layout before this optimization. The user approved a 24 MiB total budget; the 1 MiB per-HTML limit remains. The scoped 252-view browser receipt is `validation/pele-source-review.json`; it does not replace the whole-site release review.
