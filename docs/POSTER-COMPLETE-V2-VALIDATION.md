## 운영 계약
한 장 우선, 추가 한 장 분량이 있으면 원고 전체를 재배분해 각 장을 완결한다. sharedRefs·focus·splitReason과 시각 검토 필수. 작은 기기라고 페이지 수를 늘리지 않는다. 글자수 하한은 잔여 조각 방지용이며 포스터 품질/의미를 대신 평가하지 않는다.
1초는 실제 두 장 이상일 때만 적용. PKM 한 장에서는 재생 UI 대신 크게 읽기. 구버전 공개본은 엔진핀 유지, 이 시험본만 명시적 v2 재편집.
