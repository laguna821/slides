# 포스터·프로젝트·운영 규약 통합

사진에서 가져온 원칙은 장식 복제가 아니라 빠른 설명, 자료의 목적과 대상, 실제 산출물 바로가기, 월별 탐색이다. 기존 Achmage 브랜드와 작은 테마 버튼은 유지한다.

구현 범위: 프로젝트별 포스터 리소스/버전, 포스터 갤러리, 포함 자료 필터, 본문 검색, 월별 묶음, 등록 상태, 카드 산출물, 중앙 메뉴·정책, 전수 검증과 배포 영수증. 현재 승인된 개인 포스터 0건이므로 갤러리는 안내를 표시한다. EJ 결과물은 개인 포트폴리오에 포함하지 않는다.

공통 포스터 스킬 rc6은 EJ rc5의 내용·레이아웃·PDF 개선을 승계하고 도구 UI를 축소한다. OS master·로컬 스킬·EJ 공식 배포를 같은 실행 코드로 맞춘다. EJ 전체 배포판 번호는 rc7이며 포스터 스킬 번호 rc6과 별개다.

단계: 스키마/뷰어 → 실제 공개본+테스트 원고 → 독립 검토 → OS 인제스트/EJ 업데이트 → 기존 공개 포스터 교체 → 사이트 전체 검사 → GitHub/Vercel → 실제 주소 검증.
