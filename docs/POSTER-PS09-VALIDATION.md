# PS09 · HTML 순환과 독립 A2 한 장
정책 2.3.0 / 스킬 1.2.0-rc.4 / EJ 1.0.0-rc.13

기본 테마를 라이트·다크 교차로 바꿨다. 명시적으로 선택한 고정 테마는 새 저장 키에 보존한다. 4초 순환과 장 사이 공통 기하는 유지하며, 세로 모바일에서 후보별 표시폭을 우선해 좁은 중앙 띠를 줄였다.

A2는 HTML 두 장과 독립적으로 한 장에 편집했다. 네 연사의 원고와 행사 정보·일정·참여 조건·출처를 2열로 조판했다. 화면 장수를 종이에 복제하지 않는다. 명시적 종이 다장 요청만 예외로 허용한다.
