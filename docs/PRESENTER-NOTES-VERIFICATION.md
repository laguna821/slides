# 발표자 노트 잠금 검증 · 2026-10-13

공개 운영 v2는 N 창에서 “포함된 노트 없음”을 표시하고 암호란이 없었다. 최근 승인 엔진 적용본은 Educational Harness Engineering 38장 리메이크 한 작품이며, 나머지 세 발표는 보존된 구형 원본이다.

v2-notes의 라이트/다크 두 HTML은 원본 v2에서 단일 암호화 JSON 데이터만 교체했다. 원본38장·엔진·스타일·이미지·PDF·읽기 원고는 유지한다. 빈 노트를 암호화한 상태이며 새 대본을 만들었다는 의미가 아니다.

- Edge 실제 N 키 → 별도 암호창 확인.
- 두 파일 모두 지정한 프로젝트 기본 암호로 복호화, 잘못된 암호 거부, 다시 잠그기, 재로드 잠금 확인.
- P 모드의 내장 패널 잠금 확인. 실제 브라우저 팝업 차단 설정을 켠 자동 fallback 전환은 이번에 재현하지 않았다.
- 팝업의 마우스/스크린샷 CDP 시간초과는 키보드 입력과 같은 노트 URL의 일반 탭 캡처로 대체했다. 제품의 암호 오류로 분류하지 않았다.
- 독립 검토에서 고정 세 작품 예외, 실제 slide ID, 엔진 provenance, 노트 유무 증명을 보강했다.
- 별도 최종 검증자가 합성 암호로 Python8개 테스트를 실행했다. TypeScript 신규3개와 전체58개 테스트,97파일 타입검사, 한영 빌드 통과.
- 변경된 한영 화면8개 ×375/768/1440 ×light/dark =48개 실측에서 가로 넘침과 깨진 이미지 없음. 110% 브라우저 배율을 실측 후 보정했으며 최초341px 진단은 통과 증거로 쓰지 않았다.
- 기존 전체 화면·읽기·PDF 검수는 변경되지 않은 코드/파일에 한해 이전 증거를 보존한다. 새 N 동작 검수는 별도 manifest의 출력 해시에 결합한다.

정책5.1/5.2에 따라 운영 배포는 구체적 결과에 대한 사용자 확인 후 진행한다.
