# 웹 배포 용량 규약 · 6.0.0

2026-10-13 승인: PDF·ZIP은 웹에 게시하지 않는다. HTML·웹 읽기·Markdown은 유지하고 콘텐츠 이미지와 내장 폰트는 분리한다. 이 문서는 과거 규약의 PDF 필수 게시 및 웹 HTML 바이트 보존 조항을 대체한다. 발표 내용·기존 HTML 주소·엔진핀·노트 잠금·한영·게시 확인은 유지한다.

## 원본과 배포

`public/` 및 루트의 발표 원본은 보존·검증용 입력이다. Astro의 `dist/`도 중간 산출물이며 배포하지 않는다. Vercel Output Directory는 **web-dist**만 사용한다. 기존 원본과 과거 Git 이력을 삭제하거나 재작성하지 않는다. 원본 보관 해시 검사 뒤 웹 파생본을 별도로 만든다.

- PDF·ZIP 파일과 다운로드 버튼·공개 메타데이터는 제거한다. 이전 다운로드 URL은 대응 웹 읽기·포스터·발표로307연결한다.
- CMDS Eagle에 이미 설정된 R2 Worker 업로드를 재사용한다. 인증은 `CMDS_EAGLE_CONFIG` 또는 무시되는 `.local/asset-config.json`의 `cmdsEagleConfig` 경로에서 읽는다. 비밀 값은 복사·출력·커밋하지 않는다.
- 콘텐츠 이미지의 내용 해시, 공개 URL, 공개 응답 SHA256, 형식, 크기를 `content/web-assets.json`에 기록한다. 같은 파일은 여러 발표본이 공유한다. R2의 다른 자산을 삭제하거나 기존 키를 덮어쓰지 않는다.
- 내장 폰트는 동일 바이트의 공용 웹폰트로 분리한다. 이미지 모드 SVG는 외부 폰트를 읽지 못하므로 내장 폰트를 정확히 복원하여2배 PNG 파생본을 만든 뒤 R2에 저장한다. 원본 SVG는 남긴다. 글자·도표 시각 검증이 필수다.
- 기존 R2 공개 주소는 r2.dev이다. 이는 개발용·요청 제한이 있는 주소로, 이번 기존 경로 재사용이 운영 SLA를 보장하지 않는다. 새로운 공개 도메인 설정은 인증 확보 후 별도 진행한다. 오류를 숨기거나 내장형으로 자동 후퇴하지 않는다.

## 준비와 차단

`npm run upload:prepare`: 원본 빌드 → R2 자산 준비 → 웹 파생본/이전 URL 연결 갱신 → 기존 검증 및 게시 요청서. 자산 등록은 명시적으로 공개된 이 저장소의 dist만 대상으로 하며, Dropbox 전체나 다른 자료를 자동 업로드하지 않는다.

CI/Vercel의 `npm run build`는 자산 업로드를 하지 않는다. 미등록·변경된 이미지 또는 내장 자산을 만나면 실패한다. 원격 자산 업로드와 검증은 준비 단계에서 완료해야 한다.

`npm run storage:check`는 최종 결과의 PDF·ZIP, 내장 이미지·폰트, 콘텐츠 로컬 이미지, 깨진 로컬 링크, HTML2MiB/전체50MiB 초과를 차단한다. 작은 `brand/` SVG 아이콘·로고만 로컬 이미지로 허용한다. 신규 자산도 동일 규칙을 따른다. 저장 용량은 `validation/storage-report.json`에 보고한다.

미리보기는 `npm run preview`의4331포트에서 **실제 web-dist**를 제공한다. 원본 dist 화면을 검토한 것으로 웹 파생본 검증을 대신하지 않는다. 기존 UI·노트·독립 포스터 검토와 `release:verify`, 배포별 사용자 확인을 유지한다.

## 배포 실행

모든 push/PR에서 CI 검증은 유지한다. git.deploymentEnabled는 **:false, main:true로 일반 브랜치 자동 배포를 차단한다. Vercel 프로젝트의 Ignored Build Step도 Only build production으로 설정한다. 필요한 미리보기만 대시보드에서 검토 커밋으로 수동 생성하고, 무시된 빌드 단계는 해당 수동 실행에서만 건너뛴다. 검토 결과와 일치하는 현재 사용자 승인 이후에만 main에 통합한다.

PR #19 설문척도 강의는 경량화와 함께 통합한다. 기존 원본과 설명·실험실·퀴즈·노트 잠금은 보존하며 강의 PDF도 배포에서 제외한다. R2 URL 검증은 공개 요청에 한정하고 키는 로컬 CMDS 설정에만 둔다.

SVG 글꼴 검증: 변수 글꼴의 750 등 비표준 굵기는 정확한 정적 인스턴스와 전용 family로 렌더링한다. 영문 그림의 `font-family:...!important`도 해당 인스턴스를 가리키도록 인라인 우선순위를 보존한다. SameTone 표본의 U+2014(—) 한 글자는 원본 글꼴에 없어 브라우저가 사용하던 Times New Roman 기호 대체를 동일하게 유지한다. 이 처리는 원본 SHA256 `97a39d48cc53cdd6117a0d082f822524866ab3764e8a5ea77e8fdd78be91f6f0`에만 적용하며 본문 글꼴은 교체하지 않는다. glyph coverage와 원본/파생본 화면을 함께 확인한다.

## 6.0.1 · 수업용 외부 패키지 링크
2026-10-19 요청에 따라 Socratic Advisor 0.1.0의 스킬과 학생용 빈 볼트 두 개만 GitHub Release의 버전 고정 ZIP 링크로 제공한다. scripts/web-assets.ts의 정확한 두 URL만 허용한다. ZIP 파일은 web-dist에 넣지 않으며 일반 PDF·ZIP 제외와 용량 검사는 유지한다. 외부 패키지의 HTTP·SHA256을 따로 확인한다.

## 6.1.0 · 반복 코드 공유와 더 작은 배포 한도

2026-10-19 추가 다이어트 요청을 반영한다. 실제 배포 전체는 **20MiB**, 개별 HTML은 **1MiB** 이하로 제한한다. 검사기는 정책의 수치를 직접 사용한다. PDF·ZIP·내장 이미지/폰트·로컬 콘텐츠 이미지 금지는 그대로다.

웹 파생본에서 내용이 정확히 같은 익명 CSS·일반 JavaScript가 두 번 이상 나오면 해시가 붙은 공용 파일로 한 번만 저장한다. 코드 바이트, CSS 적용 순서, 스크립트 실행 순서는 보존한다. JSON·암호화 노트·이름 있는 스크립트·모듈·currentScript 의존 코드·상대 경로를 가진 CSS는 이 처리에서 제외한다. 원본 HTML과 엔진 핀은 보존한다.

바이트가 완전히 동일한 웹 HTML은 하나만 배포하고 나머지 주소를 307로 연결한다. 원본 파일은 보존한다. 내용·테마·노트가 다른 HTML을 비슷하다는 이유로 합치지 않는다. 연결은 한 번만 거치며 기존 문단 주소의 fragment는 브라우저가 유지한다. 복구는 원본에서 다시 빌드한다.

새 강의의 노트 암호화 전 원본은 `content/web-source-only.json`에 명시해 검증용 원본으로만 보관한다. 노트 원장에 등록된 source만 가능하며, 실제 공개 artifact·포스터 HTML을 이 목록에 넣으면 실패한다. 기존에 공개된 주소에는 이 제외를 소급 적용하지 않는다.

공용 폰트 7.8MiB의 R2 이전은 사용자 요청으로 다음 작업에 보류했다. 현재 글꼴 파일은 그대로 유지한다. 이전하려면 먼저 해당 공개 버킷의 CORS와 실제 브라우저 폰트 로딩을 확인해야 하며, 업로드 성공만으로 완료 처리하지 않는다.
