## 원본 보존과 잠금

`source.html`(37.4 MB)은 엔진 출력에서 테마 글꼴 참조와 다크 그림·자료 규칙만 더한 사이트 원본입니다. `content/web-source-only.json`으로 배포에서 제외합니다. `index.html`은 승인된 노트 패키저로 암호화 봉투만 추가했습니다(sha256 `f52e3e98…`). 노트 내용은 비어 있으며 노트를 제공한다고 소개하지 않습니다. 암호는 강사가 숨김 입력란에 직접 입력했고 파일·명령줄·로그에 기록하지 않았습니다.

잠금 확인(Edge headless, Playwright 1.62.1, 127.0.0.1)에서 다음이 모두 통과했습니다.
- N 키로 노트 창이 열림
- 틀린 값을 거부함
- 강사 암호로 해당 창만 해제되고 발표 창은 잠긴 상태를 유지함
- 다시 잠그기, 재해제 후 새로고침하면 잠김
- 새 발표 탭에서 N을 누르면 잠긴 창이 열림
- 팝업 차단 상황(window.open이 null을 돌려주도록 모의)에서는 잠긴 내장 패널로 대체됨

## 이번 등록에서 새로 다룬 것

- 읽기 원고 생성: R 코드·콘솔 출력은 코드 블록, 표는 칸마다 번역되는 Markdown 표로 옮겼습니다. 여러 줄 문단은 줄마다 번역 단위로 두었습니다. 산문의 `~`(GFM 취소선)·줄머리 번호(“1) 모집단 :”) 등은 Markdown이 바꾸지 않도록 이스케이프했습니다.
- R2 공개 주소(r2.dev)가 대량 업로드·점검 중 느려져 자산 동기화가 두 번 시간 초과로 멈췄습니다. 선생님 지시(“야 그걸 왜 일일히 또 대조해 패스하고 빨리 등록해”)로 이미 대조한 그림은 다시 받지 않고 새 그림만 대조하도록 바꿨습니다([저장 계약](STORAGE-CONTRACT.md)). 같은 원칙으로 공용 폰트도 등록부가 그대로면 지난 확인 영수증을 재사용합니다.
- 미리보기 서버가 r2.dev 지연으로 응답 도중 오류를 내며 꺼지던 문제를 고쳤습니다(대리 응답을 한 번만 받아 보관, 시간 초과 재시도, 헤더 전송 뒤 오류는 연결만 끊음).
- 선생님 지시(“뭔 테스트를 이렇게 많이 계속 해 올리라니까 다 패스하고”)로 바뀐 경로만 다시 검수합니다([게시 규약](UPLOAD-CONTRACT.md)).
