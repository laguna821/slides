1종 오류와 2종 오류

  • 1종 오류 (Type I error, False Positive): 실제로는 효과가 없거나 차이가 없음에도 불구하고, 우연히 얻은 샘플 데이터로 인해 효과가 있다거나 차이가 있다는 잘못된 결론을 내리는 경우
  • 2종 오류 (Type II error, False Negative): 실제로는 효과가 있거나 차이가 있음에도 불구하고, 샘플 데이터의 변동성 때문에 그 효과를 감지하지 못하고 '효과가 없다'거나 '차이가 없다'는 잘못된 결론을 내리는 경우

P-value와 가설검정

통계학의 기본 논리 구조 (2):

  • 내 말은 95%확률로 맞고 5% 확률로 틀리다
  • “내 말이 맞는 경우”의 진술문 – ‘사탕이 N개~M개 (예 6-10개) 사이에 있다’ (대립가설 / H1)
  • “내 말이 틀린 경우”의 진술문 – ‘사탕이 N개~M개 (예 6-10개) 사이에 있지 않다’ (귀무가설 / H0)

“가설”은 어떻게 만드나요?

  • 0단계: “내가 하고 싶은 맞는말”을 설정하기 위해서:
    • 독립변인 (Independent Variable)을 설정한다 – A
    • 종속변인 (Dependent Variable)을 설정한다 – B
    • A가 B에 영향을 준다는 식으로 문장을 쓴다 (A → B)
  • 독립변인 : 뭔가에 영향을 ‘주는’ 변인 (A → B)
  • 종속변인 : 뭔가로부터 영향을 ‘받는’ 변인 (A → B)
  • 중요한건, IV와 DV 모두 ‘숫자’로 측정이 ‘쉬워야’한다
  • 기본적으로, IV 한 개, DV 한 개다 (A 1개, B 1개) – 문장안에 딱 두개다
  • 중간에 화살표가 있어야 한다 (→)

다음의 경우의 수만 기억하세요 (가설의 기본 구조):

  • A가 늘어나는데 B가 줄어든다 (A↑ → B↓)
    • 다른 말로 A가 줄어드는데 B가 늘어난다 (A↓ → B↑)

이런 종류의 가설은 만들면 안됩니다:

  • A가 늘어나다가 줄어들면 B가 줄어들다가 늘어난다

  • A가 어느 시점까지는 늘어나다가 다시 줄어들수록, B는 어느 시점까지 늘어나다가 다시 늘어날 것이다

“가설”의 설정 및 검증 과정 총 정리

  • 0단계: “내가 하고 싶은 맞는말”을 설정하기 위해서:
    • 독립변인 (Independent Variable)을 설정한다 – A (성별)
    • 종속변인 (Dependent Variable)을 설정한다 – B (녹차 사탕)
  • 1단계: “내가 하고 싶은 맞는말”을 설정한다
    • A가 B에 영향을 준다는 식으로 문장을 쓴다 (A → B)
    • 예: 여자가 남자보다 녹차사탕을 더 많이 먹는다 (H1: 대립 가설)
  • 2단계: 위에 1단계를 뒤집는 “내 말을 틀리게 만드는”, 1단계 문장의 반대문장을 쓴다 (귀무가설/영가설/H0) - ‘효과가 없다’는 식으로 쓰는게 중요
    • 거의 대부분의 경우 “효과가 없다/ 관련이 없다”가 H0
    • A와 B가 관계가 없다/영향이 없다 는 식으로 쓴다
    • 예: 성별과 녹차사탕 섭취량은 관련이 없다 (H0: 귀무가설)
66 / 70가설 설정 총정리 · 2/6

66 / 70가설 설정 총정리 · 2/6

“가설”의 설정 및 검증 과정 총 정리

  • 3단계: 통계를 돌려서 유의확률이 .05 이하로 나오는지 본다
    • 유의확률 .05 이상 ( p > .05) : 효과가 없다/관련이 없다
      • 즉, 내 말이 틀렸다 (H0 이 맞다)
      • 즉, 성별과 녹차사탕 섭취량은 관련이 없다
    • 유의확률이 .05 이하 ( p < .05) : 효과가 많다/적다
      • 즉, 내 말이 맞다 (H1이 맞다)
      • 즉, ‘여자가 남자보다 녹차사탕을 더 많이 먹는다 (H1: 대립 가설)’고 말했던 내 말이 맞다
  • 4단계: 통계를 돌려서 효과의 크기 (Effect size)를 본다
    • 내 말이 맞긴 맞는데 얼마나 쎄게/약하게 맞는 말인가
    • 여자가 남자보다 녹차사탕을 하루 평균 0.5개 더 먹더라
    • (혹은) 여자가 남자보다 녹차사탕을 하루 평균 10개 더 먹더라

Caveat. 교수님, 가설에 변인이 3개로 보이는데요?

  • 가설: 여자가 남자보다 녹차사탕을 더 많이 먹는다 (H1: 대립 가설)
  • … 이 문장은 아래 내용과 논리적으로 똑같습니다:
    • A가 늘어날수록 B도 늘어난다 (A↑ → B↑)
    • 가설: 성별이 여자일수록 (A↑ → ), 녹차사탕 섭취량이 늘어난다 (B↑)
  • “당신의 성별은 무엇입니까?”
    • 1- 남자
    • 2- 여자

  • 남자/여자는 “성별”이라는 1개 변인에 들어가는 “세부 옵션”인 겁니다
    즉, “여자가 남자보다”라는 구절 통째로 “변인”이 “성별” 1개다 (위 H1에서 변인이 총 2개다)
