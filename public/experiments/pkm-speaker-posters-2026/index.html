지식 구조를 먼저 설계하다

구요한 · 커맨드스페이스

더 나은 질문을 반복하는 데서 나아가, AI가 참조할 자료와 규칙을 축적한다.

맥락 설계
질문에 지식·도구·규칙을 연결하고, 검증 결과를 다음 작업의 맥락으로 되돌린다.
기록의 경계
원본 자료, AI가 정리한 Wiki, 사람이 판단한 기록을 구분한다. 오류를 고칠 때 원출처까지 거슬러 올라간다.
작게 시작
논문 한 편의 저자·날짜·상태·출처를 남기고, 기존 노트에 연결한 뒤 실제 집필에 다시 쓴다.

사용·평가·검토를 분리하다

김진영 · 네이버 검색 US

AI가 목표를 가진 사용자처럼 서비스를 이용하게 하고, 실패 과정을 재현 가능한 기록으로 남긴다.

역할 분리
사용자 AI는 행동을, 평가 AI는 성공 여부와 근거를, 검토 AI는 판정의 일관성을 맡는다.
증거 보존
원본 대화와 행동은 보존한다. 기준과 판정은 버전으로 남겨 필요한 평가 단계만 다시 실행한다.
현실 검증
가상 사용자는 실패 후보를 넓게 찾는 수단이다. 실제 행동의 효과와 동기는 A/B 테스트·사용자 조사로 확인한다.

안창현 · 한림대학교 미디어스쿨

AI가 만든 요약을 모으는 것과 내가 이해한 것은 다르다. 읽기와 쓰기의 주도권을 기록으로 남긴다.

읽기
원문을 읽고 AI에 질문한 뒤 다시 대조한다. 왜 읽었는지, 무엇을 생각했는지, 다음 확인은 무엇인지 적는다.
판단 기록
메모·전사를 원음과 대조하고 뜻과 뉘앙스를 수정한다. 근거, 조건, 예외, 채택·보류 이유를 함께 기록한다.
다시 쓰기
검토한 원고를 한글·PDF·웹 슬라이드에 재사용한다. 기준과 절차를 Skills로 연결하되 최종 문장은 직접 판단한다.
